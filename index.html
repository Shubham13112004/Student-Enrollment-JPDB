How it works

  1. Enter a Roll-No. The form checks JsonPowerDB (GET_BY_KEY) as soon as you leave the field.
  2. If the Roll-No is new, the remaining fields unlock and you can save a new record.
  3. If the Roll-No already exists, its data is loaded, Roll-No becomes read-only and you can update the record.
  4. Use Reset at any time to clear the form and start again.

Built with HTML5, CSS3, Bootstrap 5, jQuery AJAX and the JsonPowerDB REST API.

Connection token is read from config.js — never commit a real token.
